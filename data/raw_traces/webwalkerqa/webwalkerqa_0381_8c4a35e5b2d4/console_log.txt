# 学院党委理论学习中心组开展2021年第8次集体学习
作者：张海霞 责任编辑：卞云龙审核人：陆建峰时间：2021-06-01浏览：1424 )
) )
)
5月27日下午，学院党委理论学习中心组在2010会议室开展了2021年第8次集体学习，专题学习了党的十八大以来历史。学习由党委书记张世刚主持。
!
  
首先贾阳带领大家学习了“中国特色社会主义——进入新时代 踏上新征程”十八大以来的历史。他主要从统筹推进“五位一体”总体布局、协调推进“四个全面”战略布局、全面推进国防和军队现代化建设、坚持党的全面领导和提高党的建设质量、国家制度和治理体系建设迈出新步伐、在应对风险挑战中推进各项事业、开启全面建设社会主义现代化国家新征程等方面，全面解读十八大以来的历史和成就。
陆建峰作重点发言。他谈到自十八大以来，我国在以习近平同志为核心的党中央坚强领导下，开始实现从富起来到强起来的转变，其主要贡献可以概括为两个主要方面：一是继续深化改革开放；二是对改革开放以来出现的问题及时纠正，确保我国改革开放的航向不发生偏差。
张二华作重点发言。他谈到十八大以来的重要成就有五点：一是以壮士断腕的决心进行反腐，老虎苍蝇一起打，查处了一大批腐败分子，使党和政府重新获得人民的信任，大大增强了人民群众对党的领导、对社会主义制度的信心。二是在党和政府的正确领导下，顶住了美国的打压，展现了中国的硬实力，扩大了中国在国际上的话语权和影响力。三是为中国和世界的未来发展，中国提出了“一带一路”倡议，意义深远。四是在反对帝国主义和霸权主义方面，中国最坚决；在维护国家主权和领土完整方面，中共最坚决。五是新冠肺炎疫情期间，在党和政府强有力的领导下，很快控制了疫情，经济快速恢复，人民群众对党和政府的满意度空前提高，党和政府的凝聚力和号召力进一步提升，人民对中华复兴、对党的领导、对社会主义制度充满有信心。
肖亮带领大家学习了习近平总书记在清华大学考察时的重要讲话精神，学习了习近平总书记致厦门大学建校100周年的贺信。

# 学院党委理论学习中心组开展2021年第7次集体学习
作者：张海霞 责任编辑：卞云龙审核人：陆建峰时间：2021-05-21浏览：1391 )
) )
)
5月19日下午，学院党委理论学习中心组在2010会议室开展了2021年第7次集体学习，专题学习了改革开放新时期历史。学习由党委书记张世刚主持。
!
首先，陆建峰带领大家学习了“中共党史——崭新的篇章”改革开放的历史进程和伟大成就。他回顾了从党的十一届三中全会到中共十八大历程。改革开放是党和人民大踏步赶上时代的重要法宝，是决定当代中国命运的关键，也是决定实现“两个一百年”奋斗目标、实现中华民族伟大复兴中国梦的关键。
张世刚作重点发言。他谈到两点体会：一是只有党的自我革命才有改革开放。改革必须从党的自身做起，党需要起模范带头作用，这是中国改革开放的真实历史，也是中国改革开放的内在逻辑，没有党的自我革命就没有中国的改革开放。二是改革开放推动党不断进行自我革命。为了人民的幸福和民族的复兴，中国共产党多次拿起手术刀革除自身病症，依靠自己解决自身问题，用自己的力量完善自身建设，从而为改革开放的成功、为中国的快速发展筑牢了坚不可摧的领导力量和组织力量。从这个意义上讲，中国共产党自我革命的精神难能可贵，中国共产党不愧是一个伟大的马克思主义政党。
贾阳作重点发言。他谈到改革开放是决定当代中国命运的关键抉择，是发展中国特色社会主义、实现中华民族伟大复兴的必由之路。所以，通过学习改革开放新时期历史，我们要敢于迎难而上，突破攻坚，掀起深化改革开放的新热潮，奋力创造新时代改革开放新奇迹。
肖亮带领学习了《论中国共产党历史》中“正确认识改革开放前和改革开放后两个历史时期”章节。

# 学院党委理论学习中心组开展2021年第6次集体学习
作者：张海霞 责任编辑：卞云龙审核人：陆建峰时间：2021-05-10浏览：2638 )
) )
)
4月20日下午，学院党委理论学习中心组在2010会议室开展了2021年第6次集体学习，专题学习了社会主义革命和建设时期历史。学习由党委书记张世刚主持。
!
首先，肖亮带领大家学习社会主义革命和建设时期历史。他从1949年中华人民共和国成立到1978年党的十一届三中全会召开讲起，这段历史实现了从新民主主义向社会主义的过渡，开始了社会主义建设道路的艰辛探索。回顾奋斗历程，对于正确认识社会主义的形成和发展，坚定中国特色社会主义自信，具有重要的意义。
张世刚作重点发言。他从社会主义革命和建设时期成就、党的工作在指导方针上出现的错误、社会主义革命和建设贡献等方面，详细分享了学习心得。通过社会主义革命和建设，奠定了基本的制度基础、物质基础，为中国特色社会主义的形成提供有益的借鉴和启示。
贾阳作重点发言。他回顾了重大事件的时间节点，在社会主义革命和建设时期，中国人民在中国共产党的领导下，实现了从新民主主义向社会主义的过渡，并在此基础上开始了社会主义建设道路的艰辛探索。回顾历史，更加坚定了中国特色社会主义道路自信。

|  南华大学计算机学院开展“聚类分析的理论方法及应用”学术报告  |  
| --- |  
|  2026-04-01 12:47 文/图 汤辛巧 杨磊   |  
|   |  
|  3月31日下午，南华大学计算机学院在雨母校区崇业楼学术报告厅开展“聚类分析的理论方法及应用”学术报告活动。本次报告由研究生院、科研部、计算机学院联合主办，各教研室负责人及全体研究生参加。讲座由计算机学院院长万亚平主持。 ! 报告现场 国防科技大学计算机学院教授、博士生导师刘新旺受邀主讲。他围绕聚类分析中的数据多样性、非完整性及弱可学习性等问题，结合机器学习与人工智能发展现状，系统介绍了无监督学习和聚类分析的基本概念、关键挑战与研究价值。重点分享了其团队在多视图聚类、非完整多视图聚类、深度聚类等方向取得的代表性成果，阐释了如何通过特征融合、缺失数据处理和特征学习等方法提升聚类性能，并介绍了持续聚类分析等未来研究方向。 ! 刘新旺教授作报告主讲发言 ! 报告提问互动环节 交流环节中，现场师生围绕聚类分析与大模型技术的结合进行了提问。刘新旺教授表示，大模型可为聚类任务提供先验知识支持，聚类结果也能够为大模型训练提供辅助，二者具有良好的融合前景。此次报告内容兼具理论深度与应用导向，展现了聚类分析在智能感知、目标识别、异常检测等领域的广阔应用前景，加深了师生对聚类分析前沿进展的认识。

|  守护生命· “救”在身边 ——南华大学计算机学院与护理学院联合开展急救技能专题培训  |  
| --- |  
|  2026-04-29 10:27 文/赵汕珊 图/张家伟   |  
|   |  
|  4月26日，南华大学计算机学院与护理学院在崇业楼学术报告厅联合举办了守护生命·“救”在身边——急救技能专题培训活动。护理学院教学督导胡丽老师、基础护理教研室主任伍媚春老师、计算机学院辅导员赵汕珊老师，以及护理学院学生助教、计算机学院学生代表共同参加了本次培训。 ! 伍媚春进行理论培训 本次培训坚持理论讲授与实操训练相结合的原则，内容紧密围绕应急场景展开，兼具专业性与实用性。培训伊始，伍媚春围绕生命急救核心知识进行了系统讲解，详细阐述了突发意外现场的应急处置流程、心脏骤停的判断标准、急救操作规范与注意事项等基础理论，纠正学生日常认知中的急救误区，让大家充分认识科学施救、规范施救的重要性。 ! 护理学院学生助教进行急救示范演练 实操教学是本次培训的重点环节。伍媚春、胡丽现场演示了心肺复苏的标准操作流程，以及自动体外除颤器（AED）的开机、电极片粘贴、放电及使用的全过程，手把手指导学生，确保其准确掌握按压部位、频率、深度等关键技术要领。参训学生依次进行实操演练，认真模仿规范动作，积极请教操作难点。护理学院学生助教现场进行细致纠错与指导，有力保障了每位参训学生切实掌握核心急救技能。

|   |  
|  4月23日19：30，南华大学计算机学院在院楼D502会议室举办“携笔从戎 绽放青春”大学生征兵政策解读与军旅生涯规划宣传活动。南华大学人民武装部汪先利老师与学院退伍学生代表汪玥受邀参与宣讲。活动由学院征兵专干侯四华老师主持，学院辅导员、兄弟学院辅导员和学生共100多人参与。 ! 讲座现场 讲座现场，汪先利老师紧密结合当前国防建设的新形势，为在场师生深入解读征兵工作的各项政策法规。他不仅详细阐述了大学生应征入伍的基本条件、报名流程以及体检标准，还对大学生参军入伍在学籍保留、考研升学、就业扶持等方面的优惠政策进行了深入剖析。他还分享了学校往届参军学生的成长历程，讲述了他们在部队中淬火成钢、砥砺前行的感人故事。他激励广大同学积极响应国家号召，踊跃报名参军，在国防建设的实践中锤炼意志、增长才干，为实现强国梦、强军梦贡献青春力量。 ! 汪先利宣讲 学院退伍学生汪玥也分享了自己怀揣军旅梦想、克服重重困难最终圆梦军营的励志故事，并结合自身经历，为同学们提供了宝贵的入伍经验。在互动环节，同学们积极提问，就征兵政策、入伍后的发展等方面的问题向汪先利老师请教。汪先利老师逐一进行了详细解答，现场气氛热烈。 ! 现场答疑解惑 本次征兵宣传讲座内容丰富、讲解透彻，紧密贴合学生实际需求，让同学们对大学生入伍的相关政策有了全面、深入地了解，有效解答了大家对参军入伍的各种疑问。讲座现场气氛热烈，互动频繁，不仅增强了同学们的国防意识，也激发了大家的参军热情，为学院后续征兵工作的顺利开展奠定了坚实的基础。

|  华南理工大学陈岑教授作大规模智能模型高效能计算前沿技术专题报告  |  
| --- |  
|  2026-04-25 12:49 文：韦楸 杨磊 图：韦楸   |  
|   |  
|  4月24日下午，由南华大学科研部、研究生院及计算机学院联合主办的学术讲座在雨母校区崇业楼举行。华南理工大学未来技术学院博士生导师陈岑教授作题为《面向大规模智能模型的高效能计算技术研究》的专题报告，吸引学院众多师生参加。本次报告由学院副院长欧阳纯萍主持。 ! 讲座现场 陈岑教授围绕人工智能快速发展背景下大规模智能模型面临的算力需求、执行效率与能耗挑战，系统介绍了其团队在高效能智能计算领域的最新研究成果，重点分享了图神经网络加速、视频流智能处理、三维智能视觉、模型轻量化、动态shape图计算优化及编译器优化等方面的研究进展，为大规模智能模型高效推理提供了新思路。此外，陈岑教授还介绍了华南理工大学未来技术学院的基本情况，为学院推进学科发展和高层次人才培养提供了借鉴，也为有志继续攻读博士学位的学生拓宽了视野。 ! 陈岑教授作报告 在交流环节中，现场师生围绕Token剪裁优化策略、异构计算平台适配、研究生培养路径及未来发展规划等问题与陈岑教授进行了深入交流，现场气氛热烈。 此次学术讲座拓宽了师生对大规模智能模型高效能计算前沿技术的认识，加深了大家对人工智能底层算力支撑体系的理解，也为学院进一步加强校际学术交流、推进研究生培养和人才成长营造了良好氛围。  |

|  计算机学院荣获南华大学2025级新生才艺大赛一等奖和三等奖  |  
| --- |  
|  2026-04-14 18:06 文/赵汕珊 路月淇 图/路月淇   |  
|   |  
|  4月12日下午，南华大学2025级新生才艺大赛决赛在红湘校区南华大礼堂举行。经过激烈角逐，计算机学院的两个参赛节目凭借出色表现脱颖而出，其中舞蹈《芙蓉似锦满城花》斩获本次大赛集体类第一名，荣获一等奖，朗诵《读南华》荣获三等奖，充分展现了学院学子的卓越风采与综合素养。 由院团委艺术团舞蹈队队长文梓芸等同学编排的舞蹈节目《芙蓉似锦满城花》，以灵动优美的舞姿，生动勾勒出芙蓉花盛放的唯美意境，参演同学身着精致舞衣，舞步轻盈流畅、队形编排错落有致，将中华传统古典韵味与精湛的舞台表现力完美融合，凭借扎实的舞蹈功底和极具感染力的表演，赢得了现场评委与全体观众的一致认可，最终获得本次大赛集体类第一名，摘得一等奖桂冠。 ! 《芙蓉似锦满城花》表演照片 由院团委艺术团主持人队队长袁萍峰等同学组织的朗诵节目《读南华》，则以语言为媒、以情感为核，深情传递南华大学深厚的人文精神与高雅的校园文化，参赛同学情感真挚饱满、语调铿锵有力，依托精心打磨的朗诵稿件与默契十足的团队配合，深刻诠释了对校园文化的理解与热爱，荣获大赛三等奖。 ! 《读南华》现场照片 此次获奖展现了计算机学院学子多才多艺、奋发向上的精神风貌，体现了学院在五育融合的建设成效。未来，学院继续搭建多元育人平台，培养更多德智体美劳全面发展的时代新人。

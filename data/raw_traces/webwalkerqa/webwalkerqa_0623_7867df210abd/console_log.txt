### 5月29日停服更新公告
多多自走棋 2025-05-28
亲爱的各位棋友：
  
《多多自走棋》正式服将于5月29日 05:00（UTC+8）关闭匹配，06:00（UTC+8）开始进行停服更新维护，预计维护时间5个小时，维护期间暂时无法登录游戏，开服时间会因实际维护情况提前或推迟，请提前安排好您的游戏时间。本次更新内容如下：
  
  
【新增棋子】
女武神-瓦尔基里
种族：先民
职业：骑士
品质：稀有
生命值：700 / 1400 / 2800
攻击力：70-110 / 140-220 / 280-440
攻击间隔：1.6
攻击距离：160
护甲：7
魔法抗性：0%
技能：[闪耀连击]
快速挥舞战锤，对周围的敌人造成普通攻击物理伤害。最后一次打击时，将战锤击向地面，还会对敌人造成眩晕。
挥击/砸地额外伤害：15 / 30 / 45
眩晕时间：0.5 / 0.5 / 1
挥击范围：160
砸地范围：160 / 160 / 234
冷却时间：10 / 8 / 6
  
  
【新增种族羁绊】
先民[2]：所有先民棋子每5秒从最近的敌方棋子偷取(50+2%最大生命值)点生命值治疗自己。
先民[4]：所有友方棋子获得效果:每当累计受到超过100点治疗会对周围敌人造成等于(累计治疗量)的纯粹伤害。
单次伤害上限300，冷却时间5秒。
  
  
【新增装备】
1.恶魔手套
品质：史诗
攻击力+25
[远古恶魔]：唯一被动，携带该装备的棋子造成的所有伤害都会转化为纯粹伤害。
  
2.双生獠牙
品质：稀有
攻击力+50
[牙通牙]：唯一被动，携带该装备的棋子造成伤害时会同时伤害最多2个该目标的同名棋子。
  
  
【棋库机制调整】
1.取消扩展棋库，新增种族/职业屏蔽功能，现在可以消耗金币来屏蔽某一个种族或职业，每次仅可屏蔽一个。
2.每局游戏开始时随机抽取8个 → 10个传说棋子为本局可抽取传说棋子，其中5个传说棋子开局将被隐藏，该场对局中首次刷出隐藏棋子并购买的玩家将获得5金币奖励。
  
  
【装备屏蔽机制调整】
1.开启完整的装备宝箱并选择随机获得装备时，若可供随机的装备数量不足3件，则会屏蔽本次放弃的3件装备并将该宝箱最开始屏蔽的3件装备加入装备宝箱。
  
  
【新增圣物】
1.禁止钓鱼
该圣物生效期间，你可以免费屏蔽任意种族/职业。
  
  
【棋子调整】
1.灵魂收割者
品质：史诗 → 传说
生命值：800 / 1600 / 3200 → 1000 / 2000 / 4000
攻击力：50-60 / 100-120 / 200-240 → 50-100 / 100-200 / 200-400
护甲：4 → 6
魔法抗性：15% → 30%
移除技能[竭心脉冲]，新增技能[死神之镰]。
[死神之镰]：使用死神镰刀斩击敌人，对一个敌方棋子造成眩晕和(基础伤害+最大生命值百分比)的纯粹伤害。如果敌人被斩杀(因为该技能死亡)，对周围释放治愈新星，治愈新星会对范围内的友方单位回复一定血量。
技能类型：主动
基础伤害：300 / 400 / 500
最大生命值百分比伤害：15% / 25% / 35%
治愈新星治疗量：200 / 300 / 400
治愈新星影响范围：160 / 234 / 313
冷却时间：8 / 7 / 6
  
2.盘羊骑士
品质：稀有 → 传说
生命值：750 / 1500 / 3000 → 1100 / 2200 / 4400
攻击力：50-60 / 100-120 / 200-240 → 90-120 / 180-240 / 360-480
护甲：8 → 10
魔法抗性：10% → 20%
移除技能[圣光洗礼]，新增技能[王者祝福]。
[王者祝福]：使周围的友方棋子受到的物理伤害和魔法伤害大幅度降低，并驱散不良状态。
技能类型：主动
物理伤害减免：40% / 60% / 80%
魔法伤害减免：40% / 60% / 80%
持续时间：3 / 4 / 5
作用范围：234 / 313 / 391
冷却时间：12 / 10 / 8
  
3.剑客
[旋风刃]：
现在剑客将依据自身的攻击间隔调整技能伤害间隔，剑客的攻击速度越高，旋风刃的伤害间隔越短。
  
4.梦魇
品质：稀有 → 史诗
生命值：750 / 1500 / 3000 → 900 / 1800 / 3600
魔法抗性：20% → 30%
  
5.刺魂者
额外增加种族羁绊：先民
  
  
【羁绊调整】
1.神族
神族[6]：消耗法力值释放的技能会使自身主动技能和主动装备技能的当前剩余冷却时间减少50%。
  
  
【装备调整】
1.战争号角
[鼓舞]：唯一被动，携带者召唤的召唤物获得攻击速度+100%，持续时间+100%的效果。
  
  
【圣物调整】
1.莫莫菈之巢
绑定棋库棋子数量，若放入巢穴中的棋子对应棋库棋子数量不足以用于升星，则不会提升巢穴等级。
  
2.独眼养猪场
圣物持续时间结束后，猪将不再增加出售价值。
  
  
【其他调整】
1.野怪被击败后将会掉落金币。
2.调整了部分棋手等级提升时所需的经验值，具体调整情况如下：
当前棋手等级：升到下一级所需经验值变化
6：24 → 32
7：36 → 48
8：48 → 56
9：60 → 64
  
  
【优化】
1.对大厅界面、开箱界面、模式选择界面、战斗界面的整体布局进行了优化。
2.对棋子的初始皮肤模型进行了优化。
  
  
以上便是我们此次更新的主要内容。如有问题，请联系客服，感谢您的支持。

雾霭魔君-乌日尔
种族：夜魔

攻击力：45-95 / 90-190 / 180-380
攻击间隔：0.9

作用范围：190 / 234 / 313

持续时间：3 / 4 / 5

3.骑士
减伤护盾：减免50% → 60%的物理伤害和魔法伤害，同时获得生命恢复+10的效果，不减免纯粹伤害。
  
4.术士
术士[2]：友方棋子普通攻击吸血+10% → 20%、技能吸血+10% → 20%。
术士[4]：友方棋子普通攻击吸血+25% → 30%、技能吸血+25% → 30%。
术士[6]：友方棋子普通攻击吸血+25% → 30%、技能吸血+25% → 30%；每当有棋子阵亡时，生命值百分比最低的友方术士棋子会吸取它30%的最大生命值。
  
5.牧师
新增职业特性：免疫牧师精神控制效果。
  
6.武师
移除职业特性。

1.贪婪手套
品质：普通
唯一主动，立即消灭一个生命值低于携带者的敌方召唤物或幻象。
